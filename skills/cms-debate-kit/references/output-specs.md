# 산출물 명세

사용자 요청과 기존 양식이 우선한다. 별도 지정이 없으면 아래 파일을 작업 대상 루트의 `결과물` 폴더에 만든다. 입력 원본과 이름이 겹치지 않게 한다.

| 파일 | 필수 내용 |
|---|---|
| `발췌문_문단번호본.md` | 원본에 안정적인 번호가 없을 때만 생성. 비어 있지 않은 본문 문단의 순번과 변경하지 않은 본문 |
| `논제.md` | 최종 논제, 핵심 용어, 토론 범위, 찬반별 근거 가능 문단, 범위 밖 사항 |
| `근거카드.md` | 입장, 주장, 원문 그대로의 인용, 문단 번호, 연결 설명, 예상 반론, 한계 |
| `활동지.md` | 논제 확인, 근거 찾기, 주장-근거-설명, 반론·재반론, 성찰 작성란 |
| `루브릭.md` | 평가 요소, 3~4단계 수행 수준, 총점과 피드백란 |
| `토론로그.txt` | 발언자·입장·발언과 `근거 원문: … (문단 N)` 표기 |
| `검증리포트.md` | 인용별 판정, 유사도, 차이 또는 최근접 원문, 판정 집계 |

## 품질 기준

- 논제는 발췌문만 읽어도 의미와 범위를 이해할 수 있고 찬반 양쪽에 직접 인용 가능한 문단이 있다.
- 근거카드는 입장, 주장, 근거 원문, 문단 번호, 연결 설명, 예상 반론, 재반론 또는 한계를 포함한다.
- 근거가 없는 필드는 빈칸 대신 `발췌문에서 확인 불가`로 표시한다.
- 활동지는 논제 정의, 양쪽 근거 탐색, 주장-근거 연결, 반론·재반론, 토론 후 성찰을 포함한다.
- 루브릭의 수준별 문구는 관찰 가능한 행동으로 쓰고 단순한 `우수/보통/미흡`만 적지 않는다.

## 최종 검수표

- [ ] 입력 원본의 내용, 이름과 위치가 유지되었다.
- [ ] 모든 따옴표 인용은 원문과 글자·문장부호가 같다.
- [ ] 모든 직접 인용에 문단 번호가 있다.
- [ ] 해석과 직접 인용이 구분되어 있다.
- [ ] 발췌문 밖 근거가 없다.
- [ ] 근거가 없는 곳은 `발췌문에서 확인 불가`로 표시했다.
- [ ] 모든 새 산출물이 승인된 `결과물` 폴더에 있다.
- [ ] 인용 검증리포트의 `△`, `✖` 항목을 사람이 재검토했다.
